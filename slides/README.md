# Slide Decks

One PowerPoint per module. Open them in PowerPoint, Keynote, or Google Slides.

| Deck | Module |
|------|--------|
| `Module1_Foundations.pptx` | Day 1 - AI for Blue Team Operations |
| `Module2_Detection.pptx` | Day 2 - Traffic Analysis and Threat Identification |
| `Module3_Prompt_Engineering.pptx` | Day 3 - Prompt Engineering for Security Operations |
| `Module4_Red_Teaming.pptx` | Day 4 - Introduction to AI Red Teaming |
| `Module5_Capstone.pptx` | Day 5 - End-to-End AI-Powered SOC Workflow |

## How to use them

- The second slide of each deck (third on Day 1) is the 2-hour run sheet for that day.
- The time chip at the top right of a slide shows which block of the session it
  belongs to, for example `0:25 - 0:45  20 MIN`.
- Each lab has one slide with its goal, steps, commands, and checkpoint. The commands
  are the same ones in that module's `STUDENT_GUIDE.md`, which has the full detail and
  the expected output.
